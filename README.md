# Jornal de Teatro

Site editorial estático para `jornaldeteatro.rio.br`, com crítica, agenda e bastidores das artes cênicas, preparado para receber matérias do Correio Content Hub.

## Cloudflare Pages

- Build command: `npm run build`
- Build output directory: `dist`
- Branch de produção: `main`

O site começa em modo estático. Depois do cadastro no Hub, altere `hubEnabled` para `true` em `public/config.js` para preencher “Últimas do Palco” automaticamente.
